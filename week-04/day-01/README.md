# Week 4, day 1: what a model is, a baseline to beat, and the defence of each feature

Three exercises, one after each block, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Each one comes right after the trainer's worked example: "(we do)" means that you do the steps the trainer just showed, on a new case. The week's tables are in `course.returns`. The course made up every row. A trainer set them up before Monday.

1. [Name the label each question could learn from (we do)](exercise-01-name-the-label/README.md). What you do: name the label a case-selection question could learn from, or say that it has none. Where you work: the notebook `exercise-01-name-the-label/exercise.ipynb`, as thinking work. Done when: cell 4 prints `Done:`. [Start](exercise-01-name-the-label/) · [Answer](answers/exercise-01-name-the-label/)
2. [Compute the accuracy every model must beat (we do)](exercise-02-baseline-accuracy/README.md). What you do: count the outcomes of a label and compute the accuracy of a baseline that always predicts the most common one. Where you work: the notebook `exercise-02-baseline-accuracy/exercise.ipynb`. Done when: cell 4 prints `Done:`. [Start](exercise-02-baseline-accuracy/) · [Answer](answers/exercise-02-baseline-accuracy/)
3. [Record a feature's defence, then flag a missing amount (we do)](exercise-03-defend-two-features/README.md). What you do: record the defence of a feature and add a flag column for a missing amount. Where you work: the notebook `exercise-03-defend-two-features/exercise.ipynb`, writing two tables in your schema `course.learner_NN`: `features_flagged` and the feature record, `model_feature_record`. Done when: cell 5 prints `Done:`. [Start](exercise-03-defend-two-features/) · [Answer](answers/exercise-03-defend-two-features/)

For the trainer: each answer folder's `commands.sh` runs the exercise on a computer with no Databricks.
