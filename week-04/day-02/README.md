# Week 4, day 2: the labels and each feature checked, two candidates trained and recorded in MLflow

Three exercises, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Each reads the course's shared tables, `course.returns.model_train` and `course.returns.model_valid`, as on Monday; exercise 1 also reads your feature record from Monday. If a table cannot be read, the notebook makes the same rows from the course's setup file and says so. The course made up every file and every value.

1. [Count your labels, say their origin, mark each feature](exercise-01-labels-and-marks/README.md). What you do: record where your labels came from and mark each feature as known before or after selection. Where you work: the notebook `exercise-01-labels-and-marks/exercise.ipynb`. Done when: cell 8 prints `Done:`. [Start](exercise-01-labels-and-marks/) · [Answer](answers/exercise-01-labels-and-marks/)
2. [Fit two candidates and compare each with the baseline](exercise-02-fit-two-candidates/README.md). What you do: fit two candidates from given cells and compare each one's validation accuracy with the baseline's. Where you work: the notebook `exercise-02-fit-two-candidates/exercise.ipynb`. Done when: cell 8 prints `Done:`. [Start](exercise-02-fit-two-candidates/) · [Answer](answers/exercise-02-fit-two-candidates/)
3. [Record both fits as runs and compare them from the record](exercise-03-record-two-runs/README.md). What you do: record two fits as MLflow runs and choose a candidate from what the runs recorded.
