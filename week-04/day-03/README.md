# Week 4, day 3: the two candidates judged: four cells, precision and recall, a threshold from capacity

Three exercises, in order. Each runs in the class's Databricks workspace: open your Git folder of the course, pull, and open the exercise's notebook from it. Each reads made-up files beside its notebook, not your week 3 tables; exercise 2 also writes into your MLflow runs of Tuesday. The course made up every file and every value; nothing describes how the IRS selects returns.

What you do: put ten scored returns on the list or off it at 0.5, sort each into its cell, say what each cell means for an examiner, then read a given count of 1,000 returns. Where you work: the notebook `exercise-01-four-cells/exercise.ipynb`. Done when: cell 7 prints `Done:`. [Start](exercise-01-four-cells/) · [Answer](answers/exercise-01-four-cells/)

Where you work: the notebook `exercise-02-precision-and-recall/exercise.ipynb`, then the workspace's Experiments page. Done when: cell 5 prints `Done:`. [Start](exercise-02-precision-and-recall/) · [Answer](answers/exercise-02-precision-and-recall/)
